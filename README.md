## 1. Descripción General del Proyecto
Este repositorio contiene la implementación en Java y el análisis comparativo de dos métodos numéricos fundamentales para la interpolación polinomial:
* **Método de Polinomios de Lagrange**
* **Diferencias Divididas de Newton**

El código calcula y evalúa un polinomio interpolador dado un conjunto de nodos, demostrando computacionalmente que ambos métodos llegan al mismo resultado numérico al evaluar un punto, pero difieren en su complejidad y adaptabilidad al agregar nuevos datos.
